## Phase Goal

**As a** AI Agent developer using crud-cli, **I want to** run `crud-cli gen User --fields "id:Long,name:String" --package com.acme.demo --table sys_user` from a project with templates under `.crud/templates/`, **so that** a complete set of CRUD files appears on disk with project-correct casing and paths, with zero token-wasting boilerplate from the agent.

This plan ships the thinnest end-to-end vertical slice: ONE simple template renders to ONE on-disk file via the existing `fs_writer::plan/commit` infrastructure. JSON `--file`, front-matter, `--dry-run` UX, `--type` filter, and `[templates.outputs]` mapping are deferred to Plan 02. Plan 03 adds `validate`.

<objective>
Deliver a working `crud-cli gen <Name> --fields ... --package ... --table ...` end-to-end on the happy path (per D-G01, D-G04, D-G05, D-G06, D-G07, D-G09, D-G11, D-G12, D-G24, D-G28 layer 3, D-G29, D-G33):

1. clap parses `GenArgs` and dispatches `Commands::Gen` from `main.rs` (mirror existing `Setup` arm)
2. `field_dsl::parse_fields` converts the `--fields` string into `Vec<Field>` with closed-reason errors
3. `template_loader::discover_templates` walks `.crud/templates/` via `ignore::WalkBuilder` with `.crudignore` support
4. `gen_context::build_context` produces the Handlebars JSON context (model + case suffixes + fields + git_user_*)
5. `template_engine::new_engine` registers `pascal_case`/`snake_case`/`camel_case`/`kebab_case` helpers (no_escape already locked in Phase 1)
6. `gen_pipeline::run` renders each template, builds a `Vec<WriteTarget>` whose path mirrors the template's relative path under `.crud/templates/` (with `.hbs` stripped — D-G28 fallback layer), then calls `fs_writer::plan` + `commit`
7. `run_gen` collects a `GenReport`, emits `"生成 N 个文件"` via `cli::output::emit_success`, returns 0; on error, `exit_with_envelope`

Purpose: prove the full pipeline shape and lock the public surfaces (`GenArgs`, `GenReport`, `GenInput`, `Field`, `TemplateEntry`) so Plan 02 only adds branches (JSON input, front-matter, `--dry-run` UX, `--type`, outputs mapping) without restructuring.

Output: a binary satisfying the user story above plus a passing `tests/gen_e2e_happy_path.rs` end-to-end test.
</objective>
